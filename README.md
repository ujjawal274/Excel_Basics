# 🔍 Lookup Functions

## VLOOKUP()

Learned how to:

- Search values vertically
- Retrieve data from another table
- Use Exact Match
- Use Approximate Match
- Understand Table Arrays
- Use Column Index Number

Syntax

```excel
=VLOOKUP(Lookup_Value,Table_Array,Column_Index,Range_Lookup)
```

Example

```excel
=VLOOKUP(A2,$F$2:$H$20,2,FALSE)
```
